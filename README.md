# Bishesh Kafle — Personal Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. It is ready to publish with GitHub Pages.

## Run locally
Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `bishesh-kafle.github.io`).
2. Upload the contents of this folder to the repository root. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder at the root level.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will publish the site and show its URL in the Pages section.

## Personalise before publishing
- Add your actual LinkedIn and GitHub profile URLs if you want them displayed.
- Review the CV and project descriptions for accuracy and update them as your work evolves.
- The résumé PDF is included at `assets/bishesh-kafle-cv.pdf`.

## Design system
- Font: Inter (DM Mono reserved for small technical labels)
- Accent: `#2563EB`
- Neutrals: white, light grey and charcoal
- No gradients or purple
- One consistent reveal/hover motion system, with reduced-motion support
